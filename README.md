# SportEvent — информационная поддержка спортивных соревнований

**Учебный проект по дисциплине «Проектная деятельность в ИТ».** Вариант **Н**: «Разработка программы информационной поддержки спортивных соревнований».

## Описание

SportEvent — локальный веб-прототип для учёта соревнований, участников, регистраций и результатов. Программа рассчитывает места автоматически: для бега и плавания меньшее время означает более высокую позицию, для прыжков — большая длина.

## Запуск (Windows)

1. Установить Python 3, если он отсутствует.
2. Дважды щёлкнуть `START_WINDOWS.bat` (либо `python server.py`).
3. Открыть **http://127.0.0.1:8000**.
4. Для демонстрации можно перейти в «Участники», затем «Результаты», добавить участника и ввести результат.

Mac/Linux: `python3 server.py` или `sh START_MAC_LINUX.sh`.

Для работы с Git нужна отдельная установка [Git](https://git-scm.com/downloads).

## Автотесты

Нужен Node.js 20+; внешние npm-библиотеки не требуются.

```bash
node --test tests/*.test.mjs
```

## Особенности прототипа

- Мероприятия по трём видам спорта: бег, плавание, прыжки в длину.
- Реестр участников и регистрация на соревнование.
- Ввод/обновление результатов и турнирная таблица, включая равные места.
- Фильтрация соревнований, выгрузка протокола CSV.
- Хранение пользовательских данных через `localStorage`, восстановление демо-данных.
- Учебная версия **не содержит** настоящих учётных записей, сервера, разграничения ролей и многопользовательского режима. Это требования будущей версии, а не реализованная функциональность.

src/app.mjs                Интерфейс

## Жизненный цикл и Git

Ветки `stage/analysis`, `stage/design`, `stage/implementation`, `stage/testing`, `stage/deployment` отражают этапы жизненного цикла. Ветка `main` содержит интегрированный результат. Подробнее — `docs/WBS.md`.
