# Матрица ролей и прав доступа

**Важно:** здесь зафиксирована **целевая модель** доступа. В браузерном прототипе аутентификация и авторизация отсутствуют, поэтому реальное разграничение прав не демонстрируется.

| Операция | Администратор | Организатор | Судья | Спортсмен/зритель |
|---|---|---|---|---|
| Просмотр мероприятий | Да | Да | Да | Да |
| Создание мероприятия | Да | Да | Нет | Нет |
| Регистрация участников | Да | Да | Нет | Нет |
| Ввод результатов | Да | Нет | Да | Нет |
| Просмотр результатов | Да | Да | Да | Да |
| Настройка ролей и доступов | Да | Нет | Нет | Нет |

## Разграничение GitHub

Планируемые права для командного репозитория:
- Администратор проекта — `Admin`.
- Разработчик и тестировщик — `Write`.
- Аналитик и заинтересованные пользователи — `Read` (либо `Triage`, если нужна работа с issue).

Права `Admin/Write/Read` на GitHub и предметные роли приложения **не тождественны**. Ветки не являются механизмом разграничения прав в приложении; защита ветки GitHub и назначение участников настраиваются отдельно владельцем репозитория.
