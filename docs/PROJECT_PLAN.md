# Паспорт и план проекта

**Название:** SportEvent — информационная поддержка спортивных соревнований.  
**Метод:** каскадная модель ЖЦ, интеграционные контрольные точки Git.  
**Цель MVP:** обеспечить демонстрацию базового учёта соревнований и корректного рейтинга.  
**Стейкхолдеры:** организатор, секретарь, судья, спортсмен, зритель, разработчик.
