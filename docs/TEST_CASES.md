# План и результаты тестирования

## Автоматические тесты

Тестовый набор находится в `tests/domain.test.mjs`. Запуск: `node --test tests/*.test.mjs`.

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| T01 | Базовые записи | 3 турнира, 5 спортсменов |
| T02–T04 | Создание турнира и ошибки ввода | Создание допустимо, ошибки отклоняются |
| T05–T06 | Добавление участника | Создание допустимо, дубликат отклоняется |
| T07–T08 | Регистрация на турнир | Запись уникальна |
| T09–T11 | Добавление результата | Проверяется регистрация и положительное число, разрешено обновление |
| T12–T14 | Ранжирование | Время по возрастанию; длина по убыванию; одинаковые места |
| T15–T17 | Форматирование и экспорт | Правильные единицы, безопасный HTML, валидный CSV |

## Ручные приемочные сценарии

| Код | Действия | Ожидание |
|---|---|---|
| A01 | Запустить `python server.py`, открыть URL | Главная страница загружается |
| A02 | Добавить турнир | Карточка отражается в каталоге |
| A03 | Добавить участника, зарегистрировать | Участник присутствует в списке регистраций |
| A04 | Ввести результат, открыть таблицу | Рассчитано место, значение отформатировано |
| A05 | Нажать «Экспорт CSV» | Загружается файл протокола |
| A06 | Обновить страницу браузера | Изменения сохранились |
| A07 | Нажать «Сбросить данные» и подтвердить | Восстановлены демонстрационные записи |

Факт ручной проверки должен отражать конкретную рабочую среду. Автоматические тесты подтверждены фактическим выводом запуска и не приравниваются к проверкам безопасности или производительности.
